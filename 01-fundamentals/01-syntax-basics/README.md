# Python Syntax Basics

## Overview
In this section, we will cover the fundamental syntax of Python programming language. Understanding syntax is essential as it helps you write correct and efficient code.

## Basic Syntax
Python uses indentation to define blocks of code. It does not require braces or other symbols to indicate blocks of code.

### Example:
```python
# This is a comment
if True:
    print("Hello, World!")  # Indentation is vital here
```

## Variables
Variables are used to store data values. In Python, you do not need to declare a variable type. 

### Example:
```python
name = "John"
age = 30
```

## Control Structures
Python uses if, for, and while statements for controlling the flow of logic.

### Example:
```python
for i in range(5):
    print(i)
```
